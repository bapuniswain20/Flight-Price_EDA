#  Flight Price EDA & Feature Engineering

##  Project Overview

This project performs Exploratory Data Analysis (EDA) and Feature Engineering on a Flight Price dataset.

The objective is to understand the factors affecting flight prices and prepare the dataset for further analysis and machine learning.

##  Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Excel

##  Dataset

The dataset contains information about flight prices, airlines, source and destination cities, departure and arrival times, stops, duration, class, and other features.

Dataset Source:

Kaggle - Flight Price Prediction

https://www.kaggle.com/datasets/shubhambathwal/flight-price-prediction

## 🔍 Analysis Performed

- Data Loading
- Data Understanding
- Descriptive Statistics
- Exploratory Data Analysis
- Feature Engineering
- Date Feature Extraction
- Arrival Time Feature Extraction
- Data Transformation
- Visualization

##  Feature Engineering

The project extracts useful features from the original dataset, including:

- Date
- Month
- Year
- Arrival Hour
- Arrival Minute
